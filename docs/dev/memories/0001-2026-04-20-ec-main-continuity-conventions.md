# `ec-main` Continuity Conventions

Date: 2026-04-20

## Durable Memory

`ec-main` uses serialized continuity artifacts for new bounded plans, dated notes, and durable repo memories:

- plans: `docs/dev/plans/NNNN-YYYY-MM-DD-slug.md`
- notes: `docs/dev/notes/NNNN-YYYY-MM-DD-slug.md`
- memories: `docs/dev/memories/NNNN-YYYY-MM-DD-slug.md`

Tracked repo files are authoritative for policy and planning. Graphiti is advisory operator memory for compact retrieval-oriented facts.
